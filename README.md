# Epic Universe day planner

A single-page, phone-first planner for a day at Universal Epic Universe: live waits, rain now and forecast, a re-planning ride order, walking distances and an optional location button.

Live data is fetched by the page itself from ThemeParks.wiki (waits, ride status, park hours), weather.gov (rain now at Orlando airport, hourly forecast) and Open-Meteo (rain amounts). Wait predictions come from TouringPlans' posted-wait history. Ride ratings and dizziness levels summarize published ride rankings and rider reports.
